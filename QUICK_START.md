# Быстрый старт - Установка приложения

## 📱 Установка APK

1. **Скачайте APK файл**: `Cam_assist_v1.11.apk`
2. **На вашем Android устройстве**:
   - Откройте настройки → Безопасность
   - Разрешите установку из неизвестных источников
3. **Установите приложение**: Откройте APK файл и нажмите "Установить"

## 🚗 Настройка Android Auto

### Включение режима разработчика:

1. Откройте приложение **Android Auto** на телефоне
2. Нажмите на **три точки** (меню) → **Настройки**
3. Прокрутите вниз до **О приложении** / **About**
4. Найдите строку **Версия** / **Version**
5. **Нажмите на версию 7 раз подряд** ✨
6. Появится сообщение: "Режим разработчика включен"
7. Вернитесь в настройки → **Для разработчиков**
8. Включите **Неизвестные источники** / **Unknown sources**

### Перезапуск:

- Перезагрузите телефон или очистите кэш Android Auto
- Подключите телефон к автомобилю
- Приложение появится в списке Android Auto!

## ⚙️ Сборка новой версии

Если вы разработчик и хотите собрать новую версию:

```bash
# Windows
build_release.bat

# Или вручную
gradlew.bat clean
gradlew.bat :app:assembleRelease
```

APK будет в папке `app\build\outputs\apk\release\`

## 📦 Распространение

### Варианты распространения:

1. **Прямая передача**: Отправьте APK файл пользователям через:
   - Email
   - Мессенджеры (Telegram, WhatsApp)
   - USB кабель

2. **Файлообменники**:
   - Google Drive
   - Яндекс.Диск
   - Dropbox
   - Создайте публичную ссылку для скачивания

3. **Собственный сайт**:
   - Загрузите APK на ваш веб-сайт
   - Добавьте инструкции по установке

4. **GitHub Releases** (если используете Git):
   - Создайте release с APK файлом
   - Пользователи смогут скачать напрямую

## ⚠️ Важные замечания

- ✅ Приложение работает без Google Play Store
- ✅ Не требует лицензии разработчика
- ✅ Полная функциональность Android Auto
- ⚠️ Пользователи должны включить режим разработчика Android Auto
- ⚠️ При обновлениях нужно устанавливать новый APK вручную

## 🔒 Безопасность

- Убедитесь, что пользователи доверяют источнику APK
- Рекомендуется проверять целостность файла (размер, дата)
- Для дополнительной безопасности можно подписать APK собственным ключом
