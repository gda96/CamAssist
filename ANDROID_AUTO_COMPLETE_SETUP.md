## Ключевые элементы для отображения в Android Auto

### Обязательные элементы:

1. **Intent Filter:**
   ```xml
   <action android:name="androidx.car.app.CarAppService" />
   ```

2. **Метаданные:**
   - `androidx.car.app.minCarApiLevel` - минимальный уровень API
   - `androidx.car.app.category` - категория приложения

### Рекомендуемые элементы (для лучшей видимости):

3. **Описание приложения:**
   ```xml
   <meta-data
       android:name="androidx.car.app.description"
       android:value="@string/car_app_description" />
   ```

4. **Иконка приложения:**
   ```xml
   <meta-data
       android:name="androidx.car.app.icon"
       android:resource="@mipmap/ic_launcher" />
   ```

5. **Название сервиса:**
   ```xml
   android:label="@string/app_name"
   ```

## Проверка конфигурации

### Через ADB:

```bash
# Проверка регистрации сервиса
adb shell dumpsys package com.example.cam_assist | grep -A 10 "CarAppService"

# Проверка логов Android Auto
adb logcat | grep -i "car.app"
```

### Вручную:

1. Включите режим разработчика Android Auto (см. `ANDROID_AUTO_SETUP.md`)
2. Установите приложение
3. Откройте Android Auto → Настройки → Настройка панели запуска
4. Приложение должно появиться в списке доступных приложений

## Важные замечания

### Для разработки:

1. **Режим разработчика обязателен** - Android Auto по умолчанию показывает только приложения из Google Play
2. **Неизвестные источники** - должны быть включены в настройках Android Auto
3. **Перезапуск** - после установки приложения нужно перезапустить Android Auto

### Для продакшена:

1. **Публикация в Google Play** - приложение автоматически появится в Android Auto
2. **Режим разработчика не требуется** - для пользователей из Google Play
3. **Проверка Google** - приложение должно пройти проверку на соответствие требованиям Android Auto
