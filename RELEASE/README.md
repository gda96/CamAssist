# Система управления обогревом камеры ассистентов

## Описание проекта

Проект представляет собой комплексное решение для управления обогревом камеры ассистентов на базе ESP32. Система состоит из:

- **Устройства ESP32-C3 или ESP32-C5** с датчиками температуры и влажности
- **Android приложения** для управления устройством через WiFi
- **Веб-интерфейса** для настройки и управления

## Основные возможности

- ✅ Управление обогревом вручную или автоматически
- ✅ Мониторинг температуры и влажности в реальном времени
- ✅ Подключение через WiFi (точка доступа или домашняя сеть)
- ✅ Калибровка датчиков и пороговых значений
- ✅ Настройка WiFi сетей через веб-интерфейс
- ✅ Поддержка Android Auto для автомобильных систем
- ✅ Адаптивный интерфейс для различных разрешений экрана

## Быстрый старт

### 1. Установка Android приложения

1. Скопируйте файл `Android_App/Cam_assist_v1.30.apk` на Android устройство
2. Установите APK файл (разрешите установку из неизвестных источников)
3. Запустите приложение

**Подробнее:** см. `Documentation/ИНСТРУКЦИЯ_ПО_УСТАНОВКЕ.md`

### 2. Загрузка скетча на ESP32

1. Установите Arduino IDE и настройте поддержку ESP32
2. Откройте соответствующий скетч:
   - Для ESP32-C3: `Sketches/Cam_assist_ESP32-C3.ino`
   - Для ESP32-C5: `Sketches/Cam_assist_ESP32-C5.ino`
3. Выберите правильную плату в Arduino IDE
4. Загрузите скетч на устройство

**Подробнее:** см. `Documentation/ИНСТРУКЦИЯ_ПО_УСТАНОВКЕ.md`

### 3. Подключение компонентов

Подключите датчики, реле и кнопку согласно схеме подключения.

**Подробнее:** см. `Documentation/СХЕМА_ПОДКЛЮЧЕНИЯ.md` и `Documentation/ИНСТРУКЦИЯ_ПО_РАСПАЙКЕ.md`

### 4. Первый запуск

1. После загрузки скетча устройство создаст точку доступа `Camera_Heater_AP`
2. Подключите Android устройство к этой сети (пароль: `12345678`)
3. Запустите приложение - оно автоматически подключится к устройству
4. Настройте WiFi через веб-интерфейс (откройте `192.168.4.1` в браузере)

**Подробнее:** см. `Documentation/ИНСТРУКЦИЯ_ПО_НАСТРОЙКЕ.md`

## Технические характеристики

### ESP32-C3
- **Процессор:** 32-bit RISC-V @160MHz
- **WiFi:** 802.11 b/g/n (2.4 GHz)
- **Память:** ~400 KB SRAM
- **GPIO:** 19 пинов

### ESP32-C5
- **Процессор:** 32-bit RISC-V @240MHz
- **WiFi:** WiFi 6 (802.11ax) на 2.4 и 5 GHz
- **Память:** 384 KB SRAM
- **GPIO:** 29 пинов

### Android приложение
- **Минимальная версия:** Android 7.0 (API 24)
- **Версия:** 1.30 (versionCode 31)
- **Размер:** ~10.85 MB

## Распиновка

### ESP32-C3
- **GPIO3** - Управление реле
- **GPIO2** - Кнопка TTP-223
- **GPIO8** - I2C SDA (для датчиков)
- **GPIO9** - I2C SCL (для датчиков)

### ESP32-C5
- **GPIO3** - Управление реле
- **GPIO2** - Кнопка TTP-223
- **GPIO6** - LP_I2C_SDA (для датчиков)
- **GPIO7** - LP_I2C_SCL (для датчиков)

## Требования

### Для загрузки скетча
- Arduino IDE 1.8.x или 2.x
- ESP32 Board Support Package
- Библиотеки:
  - ArduinoJson
  - WebServer (входит в ESP32 BSP)
  - WiFi (входит в ESP32 BSP)
  - Preferences (входит в ESP32 BSP)

### Для Android приложения
- Android устройство версии 7.0 или выше
- WiFi подключение

## Поддержка

При возникновении проблем:

1. Проверьте документацию в папке `Documentation/`
2. Убедитесь, что все компоненты подключены правильно
3. Проверьте версии прошивки и приложения
4. Убедитесь, что устройство и телефон подключены к одной WiFi сети
