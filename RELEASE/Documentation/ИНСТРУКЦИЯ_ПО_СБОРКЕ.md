## Требования

### Системные требования

- **ОС:** Windows 10/11, macOS 10.14+, или Linux (Ubuntu 18.04+)
- **RAM:** минимум 8 GB (рекомендуется 16 GB)
- **Диск:** минимум 10 GB свободного места
- **Java:** JDK 11 или выше

### Программное обеспечение

- Android Studio (последняя версия)
- Android SDK (API 24 и выше)
- Gradle 7.0+

## Установка Android Studio

### Шаг 1: Скачивание

1. Перейдите на официальный сайт: https://developer.android.com/studio
2. Скачайте Android Studio для вашей операционной системы
3. Запустите установщик

### Шаг 2: Установка

1. **Windows:**
   - Запустите установщик `.exe`
   - Следуйте инструкциям мастера установки
   - Установите Android SDK, Android Virtual Device и все необходимые компоненты

2. **macOS:**
   - Откройте `.dmg` файл
   - Перетащите Android Studio в папку Applications
   - Запустите Android Studio

3. **Linux:**
   - Распакуйте архив `.tar.gz`
   - Запустите `studio.sh` из папки `bin`

### Шаг 3: Первый запуск

1. Запустите Android Studio
2. Выберите "Standard" установку
3. Дождитесь загрузки всех компонентов
4. Примите лицензионные соглашения

## Настройка проекта

### Шаг 1: Клонирование или копирование проекта

Если у вас есть исходный код проекта:

1. Откройте Android Studio
2. Выберите **File → Open**
3. Выберите папку с проектом (папка, содержащая `build.gradle.kts`)
4. Нажмите **OK**

### Шаг 2: Синхронизация Gradle

1. Android Studio автоматически начнет синхронизацию Gradle
2. Если синхронизация не началась автоматически:
   - Нажмите **File → Sync Project with Gradle Files**
   - Или нажмите на уведомление "Sync Now"

3. Дождитесь завершения синхронизации
   - Это может занять несколько минут при первом запуске
   - Gradle загрузит все необходимые зависимости

### Шаг 3: Проверка настроек

1. **Проверьте версию SDK:**
   - Откройте **File → Project Structure**
   - В разделе **SDK Location** проверьте путь к Android SDK
   - В разделе **Project** проверьте версию Gradle

2. **Проверьте настройки приложения:**
   - Откройте `app/build.gradle.kts`
   - Убедитесь, что:
     - `compileSdk` = 36
     - `minSdk` = 24
     - `targetSdk` = 36

## Сборка APK

### Debug версия (для тестирования)

1. **Через меню:**
   - Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**
   - Дождитесь завершения сборки
   - APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`

2. **Через командную строку:**
   ```bash
   # Windows
   gradlew.bat assembleDebug
   
   # Linux/macOS
   ./gradlew assembleDebug
   ```

### Release версия (для распространения)

#### Вариант 1: Без подписи (для тестирования)

1. **Через меню:**
   - Выберите **Build → Generate Signed Bundle / APK**
   - Выберите **APK**
   - Нажмите **Next**
   - Выберите **Create new...** для создания keystore
   - Или используйте существующий keystore

2. **Через командную строку:**
   ```bash
   # Windows
   gradlew.bat assembleRelease
   
   # Linux/macOS
   ./gradlew assembleRelease
   ```

   APK будет создан в `app/build/outputs/apk/release/app-release.apk`

**Важно:** Этот APK подписан debug keystore и предназначен только для тестирования.

#### Вариант 2: С production подписью

1. **Создание keystore:**
   ```bash
   keytool -genkey -v -keystore app/release.keystore -alias cam_assist -keyalg RSA -keysize 2048 -validity 10000
   ```
   
   Введите необходимую информацию:
   - Пароль для keystore (запомните его!)
   - Пароль для ключа (можно использовать тот же)
   - Имя, организация и т.д.

2. **Создание файла keystore.properties:**
   
   Создайте файл `app/keystore.properties`:
   ```properties
   storeFile=release.keystore
   storePassword=ваш_пароль_keystore
   keyAlias=cam_assist
   keyPassword=ваш_пароль_ключа
   ```

3. **Обновление build.gradle.kts:**
   
   Убедитесь, что в `app/build.gradle.kts` есть следующий код:
   ```kotlin
   signingConfigs {
       create("release") {
           val keystorePropertiesFile = rootProject.file("keystore.properties")
           val keystoreProperties = Properties()
           if (keystorePropertiesFile.exists()) {
               keystoreProperties.load(FileInputStream(keystorePropertiesFile))
               storeFile = file(keystoreProperties["storeFile"] as String)
               storePassword = keystoreProperties["storePassword"] as String
               keyAlias = keystoreProperties["keyAlias"] as String
               keyPassword = keystoreProperties["keyPassword"] as String
           }
       }
   }
   ```

4. **Сборка:**
   ```bash
   # Windows
   gradlew.bat assembleRelease
   
   # Linux/macOS
   ./gradlew assembleRelease
   ```

## Подпись приложения

### Для Google Play Store

1. **Создайте production keystore** (см. выше)
2. **Сохраните keystore в безопасном месте**
3. **Запомните пароли** - без них невозможно обновить приложение
4. **Соберите release APK** с production keystore

### Для внутреннего распространения

1. Можно использовать debug keystore для тестирования
2. Для production рекомендуется создать отдельный keystore
3. Храните keystore и пароли в безопасном месте

### Важные замечания

- **НЕ теряйте keystore файл** - без него невозможно обновить приложение в Google Play
- **НЕ делитесь keystore** - это компрометирует безопасность приложения
- **Делайте резервные копии** keystore файла
- **Добавьте keystore.properties в .gitignore** - не коммитьте пароли в репозиторий

## Устранение проблем

### Ошибки компиляции

1. **Ошибки зависимостей:**
   - Выполните **File → Invalidate Caches / Restart**
   - Выберите **Invalidate and Restart**
   - Дождитесь перезапуска и повторной синхронизации

2. **Ошибки SDK:**
   - Откройте **Tools → SDK Manager**
   - Установите недостающие компоненты SDK
   - Убедитесь, что установлен Android SDK Platform 36

3. **Ошибки Gradle:**
   - Проверьте версию Gradle в `gradle/wrapper/gradle-wrapper.properties`
   - Обновите Gradle до последней версии
   - Выполните **File → Sync Project with Gradle Files**

### Проблемы со сборкой

1. **Ошибки памяти:**
   - Увеличьте память для Gradle в `gradle.properties`:
     ```
     org.gradle.jvmargs=-Xmx2048m -XX:MaxPermSize=512m
     ```

2. **Медленная сборка:**
   - Включите кэширование в `gradle.properties`:
     ```
     org.gradle.caching=true
     org.gradle.parallel=true
     ```

3. **Ошибки подписи:**
   - Проверьте путь к keystore файлу
   - Убедитесь, что пароли правильные
   - Проверьте, что alias существует в keystore

### Проверка APK

1. **Проверка подписи:**
   ```bash
   # Windows
   jarsigner -verify -verbose -certs app-release.apk
   
   # Linux/macOS
   jarsigner -verify -verbose -certs app-release.apk
   ```

2. **Проверка содержимого:**
   - Переименуйте `.apk` в `.zip`
   - Распакуйте и проверьте содержимое
   - Убедитесь, что все файлы присутствуют

## Автоматизация сборки

### Скрипт для Windows (build_release.bat)

```batch
@echo off
echo Сборка release APK...
call gradlew.bat clean
call gradlew.bat assembleRelease
if exist "app\build\outputs\apk\release\app-release.apk" (
    echo Сборка завершена успешно!
    copy "app\build\outputs\apk\release\app-release.apk" "Cam_assist_v1.30.apk"
) else (
    echo Ошибка сборки!
)
pause
```

### Скрипт для Linux/macOS (build_release.sh)

```bash
#!/bin/bash
echo "Сборка release APK..."
./gradlew clean
./gradlew assembleRelease
if [ -f "app/build/outputs/apk/release/app-release.apk" ]; then
    echo "Сборка завершена успешно!"
    cp "app/build/outputs/apk/release/app-release.apk" "Cam_assist_v1.30.apk"
else
    echo "Ошибка сборки!"
fi
```

## Рекомендации

1. **Версионирование:**
   - Обновляйте `versionCode` и `versionName` в `build.gradle.kts` перед каждой сборкой
   - Используйте семантическое версионирование (MAJOR.MINOR.PATCH)

2. **Тестирование:**
   - Всегда тестируйте APK перед распространением
   - Проверяйте на разных устройствах и версиях Android
   - Тестируйте все функции приложения

3. **Безопасность:**
   - Храните keystore в безопасном месте
   - Не коммитьте keystore и пароли в репозиторий
   - Используйте разные keystore для разных приложений
