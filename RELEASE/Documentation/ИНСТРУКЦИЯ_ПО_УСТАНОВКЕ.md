## Установка Android приложения

### Способ 1: Прямая установка APK

1. **Скопируйте APK файл на устройство:**
   - Переместите файл `Android_App/Cam_assist_v1.30.apk` на Android устройство
   - Можно использовать USB, облачное хранилище или email

2. **Разрешите установку из неизвестных источников:**
   - Откройте **Настройки → Безопасность** (или **Настройки → Приложения → Специальный доступ**)
   - Включите **"Установка неизвестных приложений"** или **"Неизвестные источники"**
   - Выберите приложение, через которое будете устанавливать (Файлы, Chrome и т.д.)

3. **Установите приложение:**
   - Откройте APK файл на устройстве
   - Нажмите **"Установить"**
   - Дождитесь завершения установки
   - Нажмите **"Открыть"** или найдите приложение в списке приложений

### Способ 2: Установка через ADB (для разработчиков)

1. **Включите режим разработчика:**
   - Откройте **Настройки → О телефоне**
   - Нажмите 7 раз на **"Номер сборки"**
   - Появится сообщение "Вы стали разработчиком"

2. **Включите отладку по USB:**
   - Откройте **Настройки → Для разработчиков**
   - Включите **"Отладка по USB"**

3. **Установите через ADB:**
   ```bash
   adb install Android_App/Cam_assist_v1.30.apk
   ```

### Проверка установки

- Приложение должно появиться в списке приложений
- Иконка: камера с символом обогрева
- Название: "Обогрев камеры ассистентов"

## Настройка Arduino IDE для ESP32

### Шаг 1: Установка Arduino IDE

1. Скачайте Arduino IDE с официального сайта: https://www.arduino.cc/en/software
2. Установите Arduino IDE на компьютер
3. Запустите Arduino IDE

### Шаг 2: Добавление поддержки ESP32

1. **Откройте настройки плат:**
   - В Arduino IDE откройте **Файл → Настройки** (или **File → Preferences**)
   - Найдите поле **"Дополнительные ссылки для менеджера плат"** (или **"Additional Boards Manager URLs"**)

2. **Добавьте URL для ESP32:**
   - Скопируйте и вставьте следующую ссылку:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
   - Если уже есть другие ссылки, добавьте новую через запятую

3. **Установите платформу ESP32:**
   - Откройте **Инструменты → Плата → Менеджер плат** (или **Tools → Board → Boards Manager**)
   - В поиске введите **"esp32"**
   - Найдите **"esp32 by Espressif Systems"**
   - Нажмите **"Установить"** (Install)
   - Дождитесь завершения установки (может занять несколько минут)

### Шаг 3: Выбор платы

1. **Для ESP32-C3:**
   - Откройте **Инструменты → Плата → ESP32 Arduino → ESP32C3 Dev Module**
   - Установите следующие параметры:
     - **CPU Frequency:** 160MHz
     - **Flash Size:** 4MB (или больше, если у вас больше)
     - **Partition Scheme:** Default 4MB with spiffs
     - **Upload Speed:** 921600
     - **USB CDC On Boot:** Enabled
     - **USB DFU On Boot:** Disabled
     - **USB Firmware MSC On Boot:** Disabled
     - **USB Mode:** Hardware CDC and JTAG

2. **Для ESP32-C5:**
   - Откройте **Инструменты → Плата → ESP32 Arduino → ESP32C5 Dev Module**
   - Установите следующие параметры:
     - **CPU Frequency:** 240MHz
     - **Flash Size:** 4MB (или больше)
     - **Partition Scheme:** Default 4MB with spiffs
     - **Upload Speed:** 921600
     - **USB CDC On Boot:** Enabled

### Шаг 4: Выбор порта

1. Подключите ESP32 к компьютеру через USB
2. В Arduino IDE откройте **Инструменты → Порт** (или **Tools → Port**)
3. Выберите COM порт, соответствующий вашему ESP32
   - На Windows обычно это COM3, COM4 и т.д.
   - На Linux/Mac это /dev/ttyUSB0, /dev/ttyACM0 и т.д.

## Установка необходимых библиотек

### Библиотеки, входящие в ESP32 BSP (устанавливать не нужно)

Эти библиотеки уже включены в ESP32 Board Support Package:
- `WiFi.h` - для работы с WiFi
- `WebServer.h` - для веб-сервера
- `Preferences.h` - для сохранения настроек
- `DNSServer.h` - для DNS сервера
- `WiFiUdp.h` - для UDP протокола

### Библиотеки, требующие установки

#### 1. ArduinoJson

1. Откройте **Скетч → Подключить библиотеку → Управлять библиотеками** (или **Sketch → Include Library → Manage Libraries**)
2. В поиске введите **"ArduinoJson"**
3. Найдите **"ArduinoJson by Benoit Blanchon"**
4. Установите версию **6.x.x** (рекомендуется последняя стабильная)
5. Нажмите **"Установить"** (Install)

**Важно:** Используйте версию 6.x.x, не версию 7.x.x, так как скетч написан для версии 6.

## Загрузка скетча на ESP32

### Шаг 1: Подготовка скетча

1. **Откройте скетч:**
   - Для ESP32-C3: откройте `Sketches/Cam_assist_ESP32-C3.ino`
   - Для ESP32-C5: откройте `Sketches/Cam_assist_ESP32-C5.ino`

2. **Проверьте настройки платы:**
   - Убедитесь, что выбрана правильная плата (см. раздел "Выбор платы")
   - Проверьте, что выбран правильный COM порт

### Шаг 2: Компиляция

1. Нажмите кнопку **"Проверить"** (✓) или используйте сочетание клавиш **Ctrl+R**
2. Дождитесь завершения компиляции
3. В нижней панели должно появиться сообщение:
   ```
   Скомпилирован скетч: XXX байт (XX%) использования памяти программы
   ```

### Шаг 3: Загрузка

1. **Подготовьте ESP32 к загрузке:**
   - Для ESP32-C3: нажмите и удерживайте кнопку **BOOT** (или **BOOT0**)
   - Нажмите и отпустите кнопку **RESET** (или **RST**)
   - Отпустите кнопку **BOOT**
   - Некоторые платы имеют автоматическую загрузку - попробуйте без нажатия кнопок

2. **Загрузите скетч:**
   - Нажмите кнопку **"Загрузить"** (→) или используйте сочетание клавиш **Ctrl+U**
   - Дождитесь завершения загрузки
   - В нижней панели должно появиться:
     ```
     Загрузка завершена
     ```

3. **Если загрузка не удалась:**
   - Попробуйте нажать кнопку RESET на плате
   - Убедитесь, что выбран правильный COM порт
   - Попробуйте уменьшить скорость загрузки (Upload Speed) до 115200
   - Проверьте USB кабель (должен поддерживать передачу данных)

### Шаг 4: Проверка работы

1. **Откройте монитор порта:**
   - Нажмите кнопку **"Монитор порта"** (🔍) или используйте сочетание клавиш **Ctrl+Shift+M**
   - Установите скорость **115200 бод**

2. **Проверьте вывод:**
   - После перезагрузки вы должны увидеть:
     ```
     Начало инициализации...
     WiFi точка доступа запущена: Camera_Heater_AP
     IP адрес: 192.168.4.1
     Веб-сервер запущен
     ```
   - Если видите ошибки, проверьте подключение компонентов

## Проверка установки

### Проверка Android приложения

1. Запустите приложение на Android устройстве
2. Убедитесь, что приложение открывается без ошибок
3. Проверьте, что отображается экран подключения

### Проверка ESP32

1. **Проверьте точку доступа:**
   - На Android устройстве откройте настройки WiFi
   - Найдите сеть **"Camera_Heater_AP"**
   - Подключитесь к ней (пароль: `12345678`)

2. **Проверьте веб-интерфейс:**
   - Откройте браузер на устройстве, подключенном к сети ESP32
   - Перейдите по адресу `http://192.168.4.1`
   - Должен открыться веб-интерфейс управления

3. **Проверьте подключение приложения:**
   - Запустите Android приложение
   - Оно должно автоматически подключиться к устройству
   - Должны отображаться данные о температуре и влажности

### Устранение проблем

Если что-то не работает:

1. **Приложение не подключается:**
   - Убедитесь, что устройство подключено к сети `Camera_Heater_AP`
   - Проверьте, что ESP32 включен и работает (светодиод мигает)
   - Попробуйте перезагрузить ESP32 (нажмите кнопку RESET)

2. **Скетч не загружается:**
   - Проверьте USB кабель
   - Убедитесь, что установлены драйверы для ESP32
   - Попробуйте другой USB порт
   - Уменьшите скорость загрузки

3. **Ошибки компиляции:**
   - Убедитесь, что установлена библиотека ArduinoJson версии 6.x.x
   - Проверьте, что выбрана правильная плата
   - Убедитесь, что установлена последняя версия ESP32 BSP
