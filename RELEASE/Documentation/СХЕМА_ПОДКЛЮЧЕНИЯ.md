## Общая схема

### Основные компоненты

1. **ESP32-C3 или ESP32-C5** - микроконтроллер
2. **Датчик GY-21 (SHT21)** - датчик температуры и влажности
3. **Реле модуль** - управление обогревом
4. **Кнопка TTP-223** - сенсорная кнопка управления
5. **Блок питания** - 5V для ESP32 и компонентов

## ESP32-C3 подключение

### Распиновка ESP32-C3 Super Mini

```
ESP32-C3 Super Mini
┌─────────────────┐
│                 │
│  [USB-C]        │  USB для питания и программирования
│                 │
│  GPIO0  ────────┤  Strapping pin (не использовать)
│  GPIO1  ────────┤  Strapping pin (не использовать)
│  GPIO2  ────────┤  Кнопка TTP-223 (A=1, B=0)
│  GPIO3  ────────┤  Управление реле
│  GPIO4  ────────┤  Свободный (можно использовать для альтернативного I2C)
│  GPIO5  ────────┤  Свободный (можно использовать для альтернативного I2C)
│  GPIO6  ────────┤  Свободный
│  GPIO7  ────────┤  Свободный
│  GPIO8  ────────┤  I2C SDA (подключен к LED - будет мигать)
│  GPIO9  ────────┤  I2C SCL
│  GPIO10 ────────┤  Свободный
│  GND    ────────┤  Общий (земля)
│  3.3V   ────────┤  Питание 3.3V
│  5V     ────────┤  Питание 5V (через USB)
│                 │
└─────────────────┘
```

### Подключение компонентов для ESP32-C3

#### 1. Датчик GY-21 (SHT21)

```
GY-21 (SHT21)          ESP32-C3
┌──────────┐
│          │
│  VCC ────┼────────── 3.3V
│  GND ────┼────────── GND
│  SDA ────┼────────── GPIO8 (I2C SDA)
│  SCL ────┼────────── GPIO9 (I2C SCL)
│          │
└──────────┘
```

**Важно:** 
- Датчик работает от 3.3V
- I2C адрес: 0x40 (по умолчанию)
- GPIO8 подключен к встроенному LED - он будет мигать при работе I2C

#### 2. Реле модуль

```
Реле модуль           ESP32-C3
┌──────────┐
│          │
│  VCC ────┼────────── 5V (или внешний источник)
│  GND ────┼────────── GND
│  IN  ────┼────────── GPIO3
│          │
│  COM ────┼────────── Нагрузка (обогрев)
│  NO  ────┼────────── Нагрузка (обогрев)
│  NC  ────┼────────── (не используется)
│          │
└──────────┘
```

**Важно:**
- Реле может требовать 5V для управления
- Если реле не срабатывает, используйте внешний источник питания 5V
- Подключите нагрузку (обогрев) к COM и NO

#### 3. Кнопка TTP-223

```
TTP-223                ESP32-C3
┌──────────┐
│          │
│  VCC ────┼────────── 3.3V
│  GND ────┼────────── GND
│  SIG ────┼────────── GPIO2
│          │
│  A ──────┼────────── 3.3V (A=1, B=0)
│  B ──────┼────────── GND
│          │
└──────────┘
```

**Важно:**
- Кнопка TTP-223 имеет два режима: A=1 (высокий уровень при нажатии) и B=0 (низкий уровень при нажатии)
- В скетче используется режим A=1, B=0
- Подключите A к 3.3V, B к GND

## Компоненты

### Датчик GY-21 (SHT21)

- **Тип:** Датчик температуры и влажности
- **Интерфейс:** I2C
- **Адрес:** 0x40 (по умолчанию)
- **Напряжение:** 3.3V
- **Точность:** ±0.3°C (температура), ±2% RH (влажность)
- **Диапазон:** -40°C до +125°C, 0% до 100% RH

### Реле модуль

- **Тип:** Одноканальное реле
- **Напряжение управления:** 5V (или 3.3V в зависимости от модуля)
- **Ток управления:** ~70mA
- **Максимальный ток нагрузки:** зависит от реле (обычно 10A при 250V AC)
- **Изоляция:** Оптоизоляция между управлением и нагрузкой

### Кнопка TTP-223

- **Тип:** Сенсорная кнопка
- **Напряжение:** 3.3V
- **Режимы:** A=1 (высокий уровень при нажатии), B=0 (низкий уровень при нажатии)
- **Чувствительность:** Настраивается (обычно через конденсатор)

### Блок питания

- **Напряжение:** 5V
- **Ток:** минимум 1A (рекомендуется 2A)
- **Тип:** USB-C для ESP32, или внешний блок питания

## Электрические характеристики

### ESP32-C3

- **Напряжение питания:** 3.3V (внутренний регулятор от 5V USB)
- **Ток потребления:**
  - Активный режим: ~80mA
  - WiFi передача: ~170mA
  - Глубокий сон: ~10µA
- **GPIO напряжение:** 3.3V
- **Максимальный ток GPIO:** 12mA (рекомендуется не более 6mA)

### ESP32-C5

- **Напряжение питания:** 3.3V (внутренний регулятор от 5V USB)
- **Ток потребления:**
  - Активный режим: ~90mA
  - WiFi 6 передача: ~200mA
  - Глубокий сон: ~10µA
- **GPIO напряжение:** 3.3V
- **Максимальный ток GPIO:** 12mA (рекомендуется не более 6mA)

### Общие рекомендации

1. **Питание:**
   - Используйте стабильный источник питания 5V
   - Рекомендуется использовать блок питания с запасом по току
   - При использовании USB, убедитесь, что порт USB может обеспечить достаточный ток

2. **Заземление:**
   - Все компоненты должны иметь общее заземление (GND)
   - Используйте короткие провода для заземления

3. **Подтягивающие резисторы:**
   - I2C линии обычно имеют подтягивающие резисторы на модуле датчика
   - Если датчик не работает, проверьте наличие подтягивающих резисторов (обычно 4.7kΩ)

4. **Защита:**
   - Реле модуль обычно имеет оптоизоляцию
   - Для защиты ESP32 от помех от реле используйте диод обратной связи на катушке реле

## Важные замечания

1. **GPIO0 и GPIO1 (ESP32-C5):**
   - Это Strapping pins - НЕ используйте их для обычных задач
   - Они используются для настройки режима загрузки

2. **GPIO8 на ESP32-C3:**
   - Подключен к встроенному LED
   - LED будет мигать при работе I2C
   - Если это мешает, можно использовать альтернативные пины GPIO4/GPIO5

3. **Реле:**
   - Убедитесь, что реле может управляться от 3.3V или используйте внешний источник 5V
   - Некоторые реле модули требуют 5V для управления

4. **I2C:**
   - Используйте короткие провода для I2C (рекомендуется не более 30 см)
   - При длинных проводах используйте подтягивающие резисторы 4.7kΩ
