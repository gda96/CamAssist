## Системные требования

### Для ESP32

- **ESP32-C3 Super Mini** или **ESP32-C5-WROOM-1**
- Датчик GY-21 (SHT21) для температуры и влажности
- Реле модуль (одноканальное, 5V)
- Кнопка TTP-223 (опционально)
- Блок питания 5V (минимум 1A, рекомендуется 2A)

### Для Android приложения

- Android 7.0 (API 24) или выше
- WiFi подключение
- Минимум 50 MB свободного места

### Для разработки

- Arduino IDE 1.8.x или 2.x
- ESP32 Board Support Package
- Библиотека ArduinoJson 6.x.x
- Android Studio (для сборки приложения)

## Быстрый старт

1. **Установите Android приложение:**
   - Скопируйте `Android_App/Cam_assist_v1.30.apk` на устройство
   - Установите APK файл

2. **Загрузите скетч на ESP32:**
   - Откройте соответствующий скетч в Arduino IDE
   - Загрузите на устройство

3. **Подключите компоненты:**
   - Следуйте инструкциям в `СХЕМА_ПОДКЛЮЧЕНИЯ.md`
   - Выполните монтаж согласно `ИНСТРУКЦИЯ_ПО_РАСПАЙКЕ.md`

4. **Настройте систему:**
   - Подключитесь к точке доступа `Camera_Heater_AP`
   - Запустите приложение
   - Настройте WiFi через веб-интерфейс

## Известные ограничения

1. **ESP32-C3:**
   - GPIO8 подключен к встроенному LED (будет мигать при работе I2C)
   - WiFi работает только на 2.4 GHz

2. **ESP32-C5:**
   - GPIO0 и GPIO1 - Strapping pins (не использовать для обычных задач)
   - Точка доступа работает только на 2.4 GHz (ограничение стандарта)

3. **Android приложение:**
   - Требуется подключение к WiFi сети устройства или домашней сети
   - Android Auto требует режим разработчика для тестирования

## Поддержка

При возникновении проблем:

1. Проверьте документацию в папке `Documentation/`

3. Проверьте версии прошивки и приложения
4. Убедитесь, что устройство и телефон подключены к одной WiFi сети
