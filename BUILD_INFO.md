## Установка

APK готов к установке. Вы можете:

1. **Скопировать на устройство** и установить вручную:
   ```bash
   adb install app/build/outputs/apk/release/app-release.apk
   ```

2. **Или скопировать файл** `app-release.apk` на Android устройство и установить через файловый менеджер

### ⚠️ ВАЖНО: Включение режима разработчика Android Auto

**Android Auto по умолчанию показывает только приложения из Google Play Store!**

Для разработки и тестирования необходимо включить режим разработчика:

1. **Настройки → Android Auto → Версия** (нажмите 7 раз)
2. Включите **"Для разработчиков" → "Неизвестные источники"**
3. Подробная инструкция в файле `ANDROID_AUTO_SETUP.md`

### Как проверить, что приложение появилось в Android Auto:

1. **Включите режим разработчика** (см. выше)

2. **Установите обновленный APK:**
   ```bash
   adb install -r app/build/outputs/apk/release/app-release.apk
   ```

3. **Перезапустите Android Auto** (полностью закройте и откройте снова)

4. **Проверьте в настройках:**
   - Настройки Android Auto → Настройка панели запуска
   - Приложение "Обогрев камеры" должно появиться в списке доступных приложений

5. **Если приложение не появилось:**
   - См. подробную инструкцию в `ANDROID_AUTO_SETUP.md`
   - Проверьте логи: `adb logcat | grep -i "car.app"`
   - Очистите кэш Android Auto
   - Переустановите приложение

## Предупреждения компиляции

Следующие предупреждения не критичны, но рекомендуется исправить:

Эти предупреждения не влияют на работу приложения.
