# iOS приложение "Обогрев камеры ассистентов"

## Описание

iOS приложение для управления устройством ESP32-C3, которое контролирует обогрев камеры ассистентов. Приложение работает как в режиме точки доступа (AP), так и в режиме подключения к домашней сети (STA).

## Возможности

- ✅ Полное управление устройством через WiFi
- ✅ Автоматическое определение режима подключения (AP/STA)
- ✅ Адаптивный дизайн для портретной и горизонтальной ориентации
- ✅ Оптимизация для iPad и CarPlay
- ✅ Поддержка CarPlay
- ✅ UDP коммуникация для автоматического обнаружения устройства
- ✅ Отображение температуры и влажности в реальном времени
- ✅ Управление обогревом и режимами работы

## Требования

- iOS 15.0 и выше
- Xcode 14.0 и выше
- Swift 5.7+
- Подключение к WiFi сети устройства или домашней сети

## API Endpoints

Приложение использует те же API endpoints, что и Android версия:

- `GET /data` - получение данных устройства
- `GET /control?action=toggle` - переключение обогрева
- `GET /control?action=auto` - установка автоматического режима
- `GET /control?action=off` - выключение режимов
- `POST /sensorcalibrate` - калибровка датчика
- `POST /calibrate` - калибровка порогов
- `POST /savehideinfo` - сохранение настройки скрытия информации
- `POST /updatewifi` - обновление WiFi настроек
- `GET /resetwifi` - сброс WiFi настроек
- `GET /restartwifi` - перезагрузка WiFi модуля

## UDP Коммуникация

Приложение использует UDP broadcast на порту 8888 для автоматического обнаружения устройства и получения данных.

## Технологии

- **SwiftUI** - современный UI фреймворк
- **URLSession** - HTTP клиент
- **GCDAsyncUdpSocket** - UDP клиент
- **Combine** - реактивное программирование
- **CarPlay** - интеграция с автомобильными системами

## Установка

1. Откройте проект в Xcode
2. Выберите вашу команду разработчика в настройках проекта
3. Подключите iOS устройство или используйте симулятор
4. Нажмите Run (⌘R)

## CarPlay

Для тестирования CarPlay:
1. Используйте симулятор CarPlay в Xcode
2. Или подключите устройство к автомобилю с поддержкой CarPlay
