## 🚀 Как скомпилировать (на macOS)

### Вариант 1: Открыть готовый проект (самый простой)

```bash
# На macOS
cd iOS_App
open CamAssist.xcodeproj
```

Затем в Xcode:
1. Выберите вашу **Team** в Signing & Capabilities
2. Настройте **Bundle Identifier**
3. Выберите устройство/симулятор
4. Нажмите **⌘R** (Run)

### Вариант 2: Через командную строку

```bash
# На macOS
cd iOS_App
chmod +x build.sh
./build.sh
```

### Вариант 3: Создать новый проект

Если `.xcodeproj` не открывается:

1. **Xcode** → **File** → **New** → **Project**
2. **App** → **SwiftUI** → **Next**
3. Заполните данные проекта
4. **Скопируйте все файлы** из `iOS_App/CamAssist/` в проект
5. **Добавьте файлы в Target**
6. **⌘R** для запуска
