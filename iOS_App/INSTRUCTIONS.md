## 📋 Как собрать приложение

### Вариант 1: Использование готового проекта (рекомендуется)

1. **Откройте Xcode на macOS**
2. **Создайте новый проект:**
   - File → New → Project
   - Выберите "App" в разделе iOS
   - Product Name: `CamAssist`
   - Interface: SwiftUI
   - Language: Swift
   - Minimum Deployment: iOS 15.0

3. **Скопируйте файлы:**
   - Скопируйте все файлы из `iOS_App/CamAssist/` в ваш Xcode проект
   - Убедитесь, что все файлы добавлены в Target

4. **Добавьте фоновое изображение:**
   - Добавьте `unnamed.png` в Assets.xcassets
   - Назовите его `background`

5. **Настройте проект:**
   - Выберите вашу команду разработчика в Signing & Capabilities
   - Настройте Bundle Identifier

6. **Соберите и запустите:**
   - Выберите устройство или симулятор
   - Нажмите ⌘R для запуска

### Вариант 2: Использование скрипта сборки

Если у вас есть доступ к macOS с установленным Xcode:

```bash
cd iOS_App
chmod +x build.sh
./build.sh
```

Этот скрипт:
- Проверит наличие Xcode
- Очистит предыдущую сборку
- Соберет приложение для симулятора и устройства
- Результаты будут в `build/Build/Products/`

### Вариант 3: Ручная сборка через Xcode

1. Откройте проект в Xcode (если создан файл .xcodeproj)
2. Выберите Product → Archive для создания архива
3. Или Product → Build для сборки

## 📱 Установка на устройство

### Через Xcode:
1. Подключите iOS устройство к Mac
2. Выберите устройство в Xcode
3. Нажмите Run (⌘R)
4. При первом запуске может потребоваться доверие к сертификату разработчика

### Через TestFlight (для распространения):
1. Создайте Archive в Xcode
2. Загрузите в App Store Connect
3. Добавьте тестировщиков в TestFlight
