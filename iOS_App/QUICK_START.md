## 🚀 Сборка на macOS (3 простых шага)

### Шаг 1: Откройте проект
```bash
# На macOS
cd iOS_App
open CamAssist.xcodeproj
```

### Шаг 2: Настройте проект
1. Выберите вашу **Team** в Signing & Capabilities
2. Настройте **Bundle Identifier** (например: `com.yourname.CamAssist`)

### Шаг 3: Соберите и запустите
- Выберите устройство или симулятор
- Нажмите **⌘R** (Run)

## 📦 Альтернатива: Создать новый проект

Если файл `.xcodeproj` не открывается:

1. **Откройте Xcode**
2. **File → New → Project**
3. **App** → **SwiftUI** → **Next**
4. Заполните:
   - Product Name: `CamAssist`
   - Team: Ваша команда
   - Organization Identifier: `com.example`
   - Interface: **SwiftUI**
   - Language: **Swift**
5. **Сохраните проект**
6. **Скопируйте все файлы** из `iOS_App/CamAssist/` в созданный проект
7. **Добавьте файлы в Target** (перетащите в Xcode)
8. **⌘R** для запуска
