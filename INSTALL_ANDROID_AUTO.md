# Инструкция по установке приложения для Android Auto

## Важно: Android Auto и локальные приложения

Android Auto требует специальных настроек для работы с приложениями, установленными не из Google Play Store. Следуйте инструкциям ниже.

## Способ 1: Прямая установка APK (рекомендуется)

### Шаг 1: Установка APK на устройство

1. Скопируйте файл `app-release.apk` на ваше Android устройство
2. На устройстве откройте настройки безопасности
3. Разрешите установку из неизвестных источников (для файлового менеджера, который вы используете)
4. Откройте APK файл и установите приложение

### Шаг 2: Настройка Android Auto для разработчиков

1. Откройте приложение **Android Auto** на вашем телефоне
2. Перейдите в **Настройки** (три точки в правом верхнем углу)
3. Прокрутите вниз до раздела **О приложении** или **About**
4. Найдите строку **Версия** (Version)
5. **Нажмите на версию 7 раз подряд** - появится сообщение "Режим разработчика включен"
6. Вернитесь в настройки - теперь появится пункт **Для разработчиков** (Developer settings)
7. Включите **Неизвестные источники** (Unknown sources) или **Разрешить неизвестные приложения** (Allow unknown apps)

### Шаг 3: Перезапуск Android Auto

1. Закройте приложение Android Auto полностью
2. Перезагрузите телефон (рекомендуется)
3. Или очистите кэш Android Auto:
   - Настройки → Приложения → Android Auto → Хранилище → Очистить кэш

### Шаг 4: Проверка

1. Подключите телефон к автомобилю с Android Auto
2. Откройте Android Auto
3. Ваше приложение "Обогрев камеры" должно появиться в списке доступных приложений

## Способ 2: Распространение через файлообменники

### Для распространения среди пользователей:

1. Загрузите APK на файлообменник (Google Drive, Dropbox, Яндекс.Диск и т.д.)
2. Предоставьте пользователям ссылку для скачивания
3. Пользователи должны следовать инструкциям из Способа 1

## Способ 3: Создание собственного репозитория APK

Можно создать простую веб-страницу с инструкциями и ссылкой на скачивание APK.

## Важные замечания

⚠️ **Безопасность**: Убедитесь, что пользователи доверяют источнику APK файла

⚠️ **Обновления**: При выпуске новой версии пользователям нужно будет вручную устанавливать обновления

⚠️ **Совместимость**: Приложение работает на Android 7.0+ (API 24+)

## Решение проблем

### Приложение не появляется в Android Auto:

1. Убедитесь, что режим разработчика включен
2. Проверьте, что "Неизвестные источники" разрешены
3. Перезагрузите телефон
4. Проверьте, что приложение установлено корректно (откройте его на телефоне)

### Ошибки при установке APK:

1. Убедитесь, что разрешена установка из неизвестных источников
2. Проверьте, что APK файл не поврежден
3. Попробуйте установить через ADB (для продвинутых пользователей)
