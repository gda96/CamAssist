# Распространение приложения "Обогрев камеры ассистентов"

## Обзор

Это приложение для управления системой обогрева камеры ассистентов через Android Auto. Приложение распространяется напрямую через APK файл, без публикации в Google Play Store.

## Требования

- Android 7.0 (API 24) или выше
- Android Auto установлен на устройстве
- Режим разработчика Android Auto включен (см. инструкцию ниже)

## Установка

### Быстрая установка

1. Скачайте файл `Cam_assist_v1.11.apk`
2. На вашем Android устройстве разрешите установку из неизвестных источников
3. Откройте APK файл и установите приложение
4. Следуйте инструкциям в файле `INSTALL_ANDROID_AUTO.md` для настройки Android Auto

## Функции

- 📊 Мониторинг температуры и влажности в реальном времени
- 🔥 Управление обогревом (включение/выключение)
- 🤖 Автоматический и ручной режимы работы
- 🔕 Режим полного выключения (только мониторинг)
- 📶 Настройка WiFi подключения
- 🔄 Перезагрузка и сброс WiFi модуля
- ⚙️ Калибровка датчиков и пороговых значений

## Поддержка Android Auto

Приложение полностью поддерживает Android Auto и отображается в списке доступных приложений после правильной настройки (см. `INSTALL_ANDROID_AUTO.md`).

## Безопасность

⚠️ **Важно**: Устанавливайте APK только из доверенных источников. Проверяйте целостность файла перед установкой.

## Обновления

При выпуске новых версий:
1. Скачайте новый APK файл
2. Установите поверх существующей версии (данные сохранятся)
3. Или удалите старую версию и установите новую

## Техническая поддержка

При возникновении проблем:
1. Проверьте инструкцию `INSTALL_ANDROID_AUTO.md`
2. Убедитесь, что все требования выполнены
3. Проверьте совместимость вашего устройства
